# Программа для ПК: «Измерение ВАХ OFET»

Qt 5.15, C++17, Qt Widgets, сборка CMake. Клиент TCP для платы на STM32.
Требования и протокол обмена: `CLAUDE.md` в корне репозитория (п. 5 и 7).

## Состав

| Файл | Назначение |
|---|---|
| `CMakeLists.txt` | проект для Qt Creator |
| `src/main.cpp` | запуск программы |
| `src/mainwindow.ui` | внешний вид окна (редактируется мышкой в Qt Designer) |
| `src/mainwindow.h`, `src/mainwindow.cpp` | логика окна: что делают кнопки, разбор ответов платы |
| `src/deviceclient.*` | TCP-связь: построчный обмен, таймаут 2 с, PING каждые 3 с |
| `src/sweepparams.*` | параметры развёртки, проверка ввода, формирование команд TRANS/OUTP |
| `src/measurementfile.*` | запись CSV для русского Excel (и файла `_wide` для выходной) |
| `emulator/ofet_emulator.py` | эмулятор платы на Python для проверки без железа |

## Сборка в Qt Creator (Windows, MinGW)

**Важно:** путь к папке проекта должен быть только из латинских букв, без пробелов и не в OneDrive, например `C:\Work\OFET_develop`. Иначе инструмент Qt `moc` выдаёт ошибку `AutoMoc subprocess error ... Cannot create moc_mainwindow.cpp` (он не умеет работать с путями вроде «Рабочий стол»).


1. Qt Creator: «Файл» -> «Открыть файл или проект» -> выбрать `pc_app/CMakeLists.txt`.
2. На странице «Настройка проекта» отметить комплект (Kit) **Desktop Qt 5.15.2 MinGW 64-bit** и нажать «Настроить проект».
   Если такого комплекта нет: «Инструменты» -> «Параметры» -> «Комплекты» -> вкладка «Профили Qt» -> «Добавить» -> указать `C:\Qt\5.15.2\mingw81_64\bin\qmake.exe`, затем на вкладке «Комплекты» создать комплект с этим профилем Qt и компилятором MinGW из `C:\Qt\Tools\mingw810_64`.
3. Собрать (Ctrl+B) и запустить (Ctrl+R).

Цифры 6.0.2 в «О программе» - это версия самого Qt Creator, а не библиотеки Qt. Программа собирается с Qt 5.15.2.

Чтобы запускать готовый `OfetMeter.exe` вне Qt Creator, рядом с ним нужно положить библиотеки Qt: в «Qt 5.15.2 (MinGW) Command Prompt» выполнить `windeployqt путь\к\OfetMeter.exe`.

## Проверка без платы (эмулятор)

Эмулятор изображает плату: принимает команды по TCP и отвечает так, как будет отвечать STM32, с выдуманным, но правдоподобным транзистором.

1. В командной строке: `python pc_app\emulator\ofet_emulator.py`
   (параметры: `--type n` для n-типа, `--speed 10` ускорить паузы в 10 раз, `--port 5000`).
2. В программе: IP `127.0.0.1`, порт `5000`, «Подключиться».
3. «Выбрать» транзистор, задать название и папку, нажать «Проходная характеристика».

## Порядок работы с программой

1. Подключиться. Индикатор: серый = нет связи, жёлтый = подключение, зелёный = связь есть, красный = ошибка или нет ответа.
2. Выбрать тип и номер транзистора, нажать «Выбрать» (плата переключит реле).
3. Задать параметры развёртки, название измерения и папку.
4. Нажать «Проходная характеристика» или «Выходная характеристика». Точки сразу пишутся в CSV.
5. «Пауза», «Продолжить», «СТОП» доступны во время измерения. «Обнулить напряжения» ставит Uзи = Uси = 0.

Файлы: `<Название>_<ГГГГММДД>_<ччммсс>_T<n>_<PROH|VYH>.csv`, для выходной ещё `..._VYH_wide.csv`
(первый столбец Uси, далее по столбцу тока на каждое Uзи). Журнал обмена: `obmen_<ГГГГММДД>.log` в той же папке.
Настройки (IP, порт, папка, все параметры) запоминаются между запусками.

## Как изменить внешний вид окна

Внешний вид хранится в `src/mainwindow.ui`. В Qt Creator: дерево проекта слева -> `OfetMeter` -> `Source Files` (или `src`) -> двойной щелчок по `mainwindow.ui`. Откроется Qt Designer (режим «Дизайн»).

- **Переставить элементы.** Элементы стоят в компоновках (сетки, столбцы), поэтому их перетаскивают мышкой между ячейками, а не ставят в произвольную точку. Размер окна и колонок подстраивается сам.
- **Изменить надпись.** Двойной щелчок по кнопке или надписи.
- **Цвет, шрифт, рамка.** Правый щелчок по элементу -> «Изменить styleSheet...». Пример для кнопки:
  `QPushButton { background: #1976d2; color: white; font-weight: bold; }`
  Так уже сделана красная кнопка СТОП. Стиль, заданный у группы или у всего окна (`MainWindow`), действует на все элементы внутри.
- **Пределы и значения по умолчанию полей.** Выделить поле, справа внизу «Редактор свойств»: `minimum`, `maximum`, `value`, `suffix`. При следующем запуске программа подставит сохранённые значения из прошлого раза.
- Сохранить (Ctrl+S) и запустить (Ctrl+R).

**Чего не делать.** Не менять у существующих элементов свойство `objectName` (например `stopButton`) и не удалять их: по этим именам код находит элементы, и сборка выдаст ошибку. Не менять порядок пунктов в списках «Тип» и «Диапазон» (код считает: «Авто» = 0, далее диапазоны 1...7). Новые надписи, рамки и картинки добавлять можно.

Цвет кружка-индикатора связи меняется в коде, функция `setLed()` в `mainwindow.cpp`, цвета вида `#43a047`.
