# Прошивка STM32F407ZET6

| Папка | Что внутри |
|---|---|
| `ofet_core/` | логика прошивки на C: протокол, развёртки, автодиапазон, реле, ЦАП. Не зависит от HAL |
| `host_sim/` | симулятор платы на ПК и автотесты логики (Linux, gcc) |
| `CUBEMX_SETUP.md` | как создать и настроить проект в STM32CubeIDE |
| `ofet_fw/` | проект STM32CubeIDE (создаётся по `CUBEMX_SETUP.md`) |

## Модули `ofet_core`

| Файл | Назначение |
|---|---|
| `ofet_config.h` | все константы: пределы, времена реле, пороги автодиапазона, тип реле диапазонов |
| `ofet_hw.h` | функции железа, которые реализует платформа (I2C, линии реле, АЦП, отправка строки, время) |
| `app.c` | старт, очередь команд, срочные команды, безопасное состояние, контроль связи |
| `sweep.c` | автомат проходной и выходной характеристик |
| `meas.c` | измерение точки с автовыбором диапазона |
| `relay_sel.c` | коммутатор транзисторов (импульсы по очереди, 50 мс) |
| `relay_range.c` | реле диапазонов ТИА (бистабильные или обычные) |
| `dac.c`, `calib.c` | AD5693R и калибровка Uвых = a * D + b |
| `proto.c` | разбор полей и вывод чисел без printf для float |

Всё неблокирующее: главный цикл платформы вызывает `app_poll()` как можно чаще, принятые строки передаются в `app_on_line()`.

## Подключение к проекту CubeIDE (когда проект будет создан)

1. Правой кнопкой по проекту -> Properties -> C/C++ General -> Paths and Symbols:
   - Includes: добавить `../../ofet_core/Inc`;
   - Source Location: Link Folder -> `ofet_core/Src`.
2. Реализовать `ofet_hw.h` в файле `Core/Src/ofet_hw_stm32.c` (будет подготовлен, когда станут известны выводы).
3. В `main.c` в USER CODE: `app_init()` перед циклом, `app_poll()` и `MX_LWIP_Process()` в цикле.

## Симулятор и тесты (на ПК с Linux или WSL)

```
cd firmware/host_sim
make test                # 19 сценариев: развёртки, STOP, PAUSE, Ilim, ошибки, потеря связи, реле
./ofet_sim --tcp 5000    # плата-симулятор для программы ПК (IP 127.0.0.1, порт 5000)
```

Симулятор печатает `!!` при нарушении правил: SET и RESET одного реле одновременно, две линии коммутатора сразу,
импульс короче 20 мс, переключение транзистора под напряжением, разрыв обратной связи ТИА, включение ±18 В до настройки ЦАП.
